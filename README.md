# ROGUE MEN

**Own the moment.**

A bold men's grooming ecommerce storefront with **36 demo products** across deodorant sprays, deodorant sticks, body wash, body sprays, grooming essentials and gift sets.

## Features
- Strong black, charcoal, white and red visual system
- Product-first layout
- Clean square product images
- Search
- Category filtering
- Scent filtering
- Product detail pages
- Wishlist
- Shopping cart demo
- Collections
- Grooming guides
- FAQ
- Shipping and returns
- Customer support
- Responsive layout
- GitHub Pages ready
